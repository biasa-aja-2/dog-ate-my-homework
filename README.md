A one-line excuse, in the dog's own voice, for why the homework got eaten. The dog did hand it in — just through a different system.

> I ate it because the teacher said hand it in, and I did — just through a different system.

## Why this line

The judge's brief wants an excuse from a dog caught eating the homework, in the dog's own voice, with a twist that lands in a single line. This one is first-person dog throughout: the dog believes it did nothing wrong — it followed the teacher's instruction literally. The punchline reframes "hand it in" as the digestive system, a piece of dog logic no person would offer, and it needs no setup or second line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dog-out python3 main.py
```
